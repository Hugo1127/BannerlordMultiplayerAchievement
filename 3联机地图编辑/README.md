## 1. 要解决的成就

| 成就 | 达成条件 | 为什么需要改地图 |
|---|---|---|
| 落井下石（Catch） | 用巨石砸死一名敌方玩家 | 官方图上可拾取的巨石/投石堆位置分散，纯靠运气 |
| 一石三鸟（Strike!） | 用投石车（Mangonel）一发击杀 3 名敌方玩家 | 需要 3 个敌人挤在同一落点，官方图很难凑 |

## 2. 已确认的结论（实测）

- **落井下石**：捡起地上的石头砸死 Bot 即可，关键是地图上要有**位置好找、数量足够**的投石堆；
- **一石三鸟**：不一定要真的操作投石车 —— 实测**用火焰投石一次击杀 3 个也算**；
- 因此最省事的思路是在自定义地图上**密集摆放投石堆与火焰投石堆**，让人和 Bot 都往这一片走。
