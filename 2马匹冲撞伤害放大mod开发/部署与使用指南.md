# ChargeTweaks 部署与使用指南

> 面向：想在自己服务器上开「马撞人 ×20」的人。看完这一篇就能装好、配好、验证好。
> 想知道它**为什么能生效**（伤害管线、IL 调研、模型注册方式），见 [docs/实现原理与开发记录](./docs/实现原理与开发记录.md)。

适用环境：`DedicatedServer`（Build 125802，服务端运行时 **.NET 8**）｜当前版本 **v1.1.0**

---

## 1. 这个模组做什么

| 项 | 内容 |
|---|---|
| 作用 | 在**服务器端**把「马撞人」的最终伤害乘以可配置倍率（默认 **20 倍**） |
| 只影响 | 坐骑冲撞这一条伤害链 |
| 不影响 | 近战挥砍、远程射击、马匹速度/操纵、击退与落马规则 |
| 客户端 | **不需要安装**，不会提示模组不匹配；玩家保持纯净客户端 |

多人对局的血量与伤害由服务器结算，客户端只做表现，所以只装服务端就能改变实际伤害。

## 2. 部署（3 步）

### 第 1 步：放模块

把本目录下的 `ChargeTweaks` 整个文件夹复制到服务器的 `Modules\` 下，最终结构：

```
DedicatedServer\Modules\ChargeTweaks\SubModule.xml
DedicatedServer\Modules\ChargeTweaks\charge_config.xml
DedicatedServer\Modules\ChargeTweaks\bin\Win64_Shipping_Server\ChargeTweaks.dll
```

> DLL 必须放在 `模块名\bin\Win64_Shipping_Server\` 这一层，少一层就加载不到。

### 第 2 步：改启动命令

编辑 `start.txt` / `start.bat`，在启动命令最前面加 `_MODULES_..._MODULES_` 参数（注意原命令是续行写法，实际是一整行）：

```bat
DedicatedCustomServer.Starter.exe _MODULES_*Native*Multiplayer*ChargeTweaks*_MODULES_ /dedicatedcustomserverconfigfile "%CONFIG_FILE%" /dedicatedcustomserverauthtoken "%AUTH_TOKEN%" /LogOutputPath "%LOG_DIR%" /tickrate "%TICK_RATE%"
```

- `ChargeTweaks` 必须排在 `Multiplayer` **之后**：模块按列表顺序加载，越靠后越优先；
- 模块名就是 `Modules\` 下的文件夹名，大小写要对得上。

### 第 3 步：启动并确认

重启服务器，控制台/日志应先出现配置行，再出现注册行：

```
[ChargeTweaks] 配置: 玩家倍率=20 AI倍率=1 友伤放大=False 每秒上限=8 伤害上限=0 日志=False | ...\Modules\ChargeTweaks\charge_config.xml
[ChargeTweaks] 已注册 ChargeDamageModel | 玩家倍率=20 AI倍率=1
```

看到这两行就算部署好了。

> 如果只看到兜底日志 `[ChargeTweaks] OnMissionBehaviorInitialize: 已强制替换伤害模型 | ...`，也算生效（这是防模型被覆盖的第二条路径），同样会打印当前倍率。

## 3. 配置

### 3.1 配置文件

编辑 `Modules\ChargeTweaks\charge_config.xml`：

```xml
<ChargeTweaksConfig>
    <PlayerMultiplier>20.0</PlayerMultiplier>       <!-- 玩家骑的马 -->
    <BotMultiplier>1.0</BotMultiplier>              <!-- AI 骑兵，1.0 = 原版 -->
    <AffectFriendlyFire>false</AffectFriendlyFire>
    <MaxEmpoweredHitsPerSecond>8</MaxEmpoweredHitsPerSecond>
    <MaxDamage>0</MaxDamage>
    <LogDamage>false</LogDamage>
</ChargeTweaksConfig>
```

### 3.2 参数说明

| 项 | 说明 |
|---|---|
| `PlayerMultiplier` | **玩家（真人）骑手**的冲撞倍率，必须 `> 0` 且 `<= 1000`；`1.0` = 原版。非法值回退 **20** |
| `BotMultiplier` | **AI 骑兵**的冲撞倍率，默认 **1.0**（与原版一致），非法值也回退 1.0。想让 AI 骑兵也变强可设 2~3 |
| `AffectFriendlyFire` | 撞到队友时是否也放大，默认 `false` |
| `MaxEmpoweredHitsPerSecond` | 每秒最多放大几次（`0~1000`），超出的冲撞按**原版伤害**结算；`0` = 不限制。默认 **8** |
| `MaxDamage` | 放大后的单次伤害上限（最大 `1000000`），`0` = 不限制 |
| `LogDamage` | `true` 时每次放大在服务器控制台打印一行，用于验证 |
| `Multiplier`（旧版键） | 老配置只写这一个键时，玩家与 AI 共用该倍率（兼容旧配置，不因换 DLL 突然变样） |

### 3.3 为什么默认 `BotMultiplier = 1.0`

实测结论：不装模组稳定、**5 机器人 + 1 真人**稳定、**13 机器人 + 1 真人约 5 分钟客户端崩溃**。

崩溃发生在客户端引擎的原生代码里（`TaleWorlds.Native.dll` 空指针），由 **agent 索引失步**触发，与「单位时间的击杀 / 重生 / 删除事件密度」高度相关。×20 让 AI 骑兵互相冲撞也变成一击必杀，会把 bot 的死亡—重生频率抬高一个量级。

`MaxEmpoweredHitsPerSecond` 是第二道保险：即使一次冲锋连续撞到一串人，也最多每秒放大 8 次。

完整的取证过程与修复复盘见 [docs/客户端崩溃排查记录](./docs/客户端崩溃排查记录.md)。

### 3.4 生效时机

改完保存 → **重启服务器**生效。

配置在进程启动时读一次并缓存，**换图不会重新读取**，所以改完不重启是看不到变化的。

## 4. 验证生效

1. 把 `LogDamage` 改成 `true`，重启服务器；
2. 进服骑马撞一次敌人，服务器控制台应输出：

```
[ChargeTweaks] 冲撞伤害 12.0 -> 240.0 (x20, 玩家骑手) | 受害者=PlayerName
```

日志会直接标出 `玩家骑手` / `AI骑手`，可按它确认倍率判定是否符合预期。
被 `MaxEmpoweredHitsPerSecond` 限流时，会打印：

```
[ChargeTweaks] 冲撞被限流（超过每秒 8 次），按原版伤害结算 | 受害者=PlayerName
```

3. 对照：同一匹马撞同一个人，不开模组时伤害约为 1/20。验证完记得把 `LogDamage` 改回 `false`，否则会刷屏。

## 5. 调参建议（稳定性优先）

| 想要的效果 | 建议 |
|---|---|
| 最稳 | `BotMultiplier=1.0`、`MaxEmpoweredHitsPerSecond=4` |
| 想让 AI 骑兵也有点强度 | `BotMultiplier=2.0`，观察 30 分钟 |
| 想更夸张 | 只提高 `PlayerMultiplier`，不要再动 `BotMultiplier` |
| 人数 / 机器人较多 | 降低 `MaxEmpoweredHitsPerSecond`，或减少 bot 数量 |

降负载还可以与服务端参数叠加：降低 `NumberOfBotsTeam1/2`、加大 `RespawnPeriod`（参数含义见[服务器参数手册](../1服务器开服教程/服务器参数手册.md)）。

## 6. 重新编译（一般用不到）

只有当官方更新服务端、出现类型加载错误时才需要重编。前置：本机装有 .NET SDK（较新版本即可）+ .NET 8 运行时。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -ServerBin "C:\DedicatedServer\bin\Win64_Shipping_Server"
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-ServerBin` | 本目录**上一级**的 `bin\Win64_Shipping_Server` | 服务器 DLL 目录；仓库单独存放时一般要显式指定 |
| `-DotnetRoot` | `C:\Program Files\dotnet` | .NET 安装根目录 |
| `-DotnetRuntimeVersion` | 自动选最新的 8.0.x | 指定运行时版本 |

成功输出：

```
OK: ...\ChargeTweaks\bin\Win64_Shipping_Server\ChargeTweaks.dll (12288 bytes)
```

> `build.ps1` 是纯 ASCII 脚本（避免 Windows PowerShell 5.1 按 ANSI 读中文导致语法错误），编译原理与踩过的坑见 [docs/实现原理与开发记录](./docs/实现原理与开发记录.md)。

## 7. 卸载 / 回滚

1. 删除启动命令里的 `*ChargeTweaks*`（或整段 `_MODULES_`）；
2. 重启服务器即恢复原版；`Modules\ChargeTweaks` 目录可以保留，不影响运行。

回滚是「立即生效、不用改文件」的，出问题先做这一步。

## 8. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 启动日志没有 `[ChargeTweaks]` | 模块没被加载 | 检查 `_MODULES_` 拼写、是否包含 `ChargeTweaks`、模块目录是否在 `Modules\` 下 |
| 有加载日志但伤害没变 | 未替换成功 / 被其它模组覆盖 | 打开 `LogDamage` 看有没有冲撞日志；确认没有其它改伤害的模组 |
| 启动时报找不到 DLL | DLL 路径不对 | 必须是 `Modules\ChargeTweaks\bin\Win64_Shipping_Server\ChargeTweaks.dll` |
| 报类型加载错误 | 服务端更新后签名变化 | 用 `build.ps1` 重新编译 |
| 控制台刷屏 | `LogDamage` 开着 | 改回 `false` |
| 数字不符合预期 | 倍率作用在最终伤害上，会被护甲减伤等前置计算影响 | 用 `LogDamage` 看真实前后数值，必要时调倍率 |
| 玩一会儿客户端崩 | 见崩溃复盘 | 先按[调参建议](#5-调参建议稳定性优先)降负载；仍崩则与倍率无关，按[docs/客户端崩溃排查记录](./docs/客户端崩溃排查记录.md)收集现场 |

## 9. 限制与注意事项

| 项 | 说明 |
|---|---|
| 只影响冲撞 | 近战、远程、马匹速度/操纵/击退规则都不变 |
| 默认只管玩家 | `BotMultiplier = 1.0`，AI 骑兵冲撞与原版一致 |
| 友伤默认不放大 | `AffectFriendlyFire = false` |
| 限流会「吃掉」部分放大 | 同一秒内超过上限的冲撞按原版结算 |
| 模组冲突 | 若还有别的模组也替换 `AgentApplyDamageModel`，后加载的生效，同一时间只有一个生效 |
| 版本升级 | 官方更新服务端后若报错，用 `build.ps1` 重新编译（源码在 `src\`） |
| 不修改 Native | 不动 `mpitems.xml`，Steam 更新不会覆盖任何东西 |
