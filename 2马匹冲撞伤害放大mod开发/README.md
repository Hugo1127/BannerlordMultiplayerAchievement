# ChargeTweaks — 骑乘冲撞伤害倍率（服务端模组）

> 在**服务器端**把「马撞人」造成的伤害乘以可配置倍率（默认 **20 倍**）。
> 客户端**不需要**安装本模组，也不会出现模组不匹配。
> 适用：`DedicatedServer`（Build 125802，服务端运行时 .NET 8）｜当前版本 **v1.1.0**

典型用途：刷「横冲直撞（Roadkill）」这类靠**坐骑冲撞击杀**累计的成就时，让撞人的那一下足够致命。

---

## 30 秒上手

1. 把本目录下的 `ChargeTweaks\` 整个文件夹复制到服务器的 `Modules\` 下；
2. 启动命令的模块列表里加上 `ChargeTweaks`（必须排在 `Multiplayer` 之后）：

   ```
   _MODULES_*Native*Multiplayer*ChargeTweaks*_MODULES_
   ```

3. 重启服务器，控制台出现下面这行即表示加载成功：

   ```
   [ChargeTweaks] 配置: 玩家倍率=20 AI倍率=1 友伤放大=False 每秒上限=8 伤害上限=0 日志=False | ...\charge_config.xml
   ```

细节（配置项、验证方法、回滚、排障）见 **[部署与使用指南](./部署与使用指南.md)**。

## 默认配置与稳定性

| 项 | 默认值 | 说明 |
|---|---|---|
| 玩家（真人）骑手倍率 | **20** | 核心体验 |
| AI（机器人）骑手倍率 | **1.0**（原版） | 稳定性关键 |
| 每秒最多放大次数 | **8** | 一次冲锋连撞多人时的突发保护 |
| 友伤是否放大 | **false** | |

> 改 `charge_config.xml` 后需要**重启服务器**才生效（配置在进程内只读一次，换图不会重读）。
>
> 只放大「玩家自己的马」是刻意的：v1.0.0 曾对所有冲撞一视同仁，在 **13 机器人 + 1 真人**的对局里约 5 分钟就会把客户端压崩（引擎的 agent 索引竞态，不是模组代码崩的）。
> 完整复盘见 [docs/客户端崩溃排查记录](./docs/客户端崩溃排查记录.md)，调参建议见[部署与使用指南](./部署与使用指南.md)。

## 限制速览

- 只改「冲撞」这一条伤害链，近战、远程、马匹速度/操纵都不变；
- 模组只装在服务端，玩家保持纯净客户端（刷成就时不建议加载任何 MOD）；
- 官方更新服务端后若报类型加载错误，用 `build.ps1` 重新编译即可（详见 [技术文档](./docs/实现原理与开发记录.md)）。
