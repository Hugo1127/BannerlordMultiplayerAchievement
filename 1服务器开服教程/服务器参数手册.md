# 骑砍2 专用服务器参数手册

> 适用对象：（Steam「Mount & Blade II: Dedicated Server」工具包，Build 125802）
> 编写方式：直接反编译/反射读取服务器程序集（`TaleWorlds.MountAndBlade.dll` 等），参数范围与说明均来自代码本身，而非网上二手资料。
> 最后更新：2026-11-16

---

## 1. 重要说明

注意区分2种不同参数：

| 层 | 文件 | 作用 | 修改后 |
|---|---|---|---|
| 启动参数 | 写在`start.bat`双击运行 | 传给 `DedicatedCustomServer.Starter.exe` 的参数：配置文件名、Token、tickrate、日志路径、模块列表 | 需重启服务器 |
| 服务器选项 | `Modules\Native\myserver_config.txt` | 服务器初始化时**逐行执行的服务器控制台命令**（等价于你在服务器窗口里一条条敲） | 需重启服务器 |

`myserver_config.txt` 的每一行就是一个控制台命令，格式 `选项名 值`。文件末尾的 `end_game_after_mission_is_over` / `start_game_and_mission` 也是命令，不是选项。

**关键限制（官方教程）**：配置文件必须放在 `Modules\Native\` 目录下才能被读取。

## 2. 启动参数一览

### 2.1 自定义服务器相关（由游戏侧解析）

从 `TaleWorlds.MountAndBlade.Module.ProcessApplicationArguments` 的 IL 中提取出的全部参数名：

| 参数 | 说明 |
|---|---|
| `/dedicatedcustomserver` | 以「自定义专用服务器」模式启动 |
| `/dedicatedcustomserverconfigfile <路径>` | 指定初始化时加载的配置文件（逐行执行） |
| `/dedicatedcustomserverauthtoken <token>` | 直接传 Token，省去 Token 文件 |
| `/dedicatedcustomservernameoverride <名字>` | 覆盖服务器名 |
| `/dedicatedcustomserverpasswordoverride <密码>` | 覆盖服务器密码 |
| `/dedicatedcustomserverDontAllowOptionalModules` | 禁止客户端带可选模块加入（强制纯净端） |
| `/playerHostedDedicatedServer` | 标记为「玩家自建服务器」 |
| `/singleplatform` | 单一平台（仅同平台玩家可见） |
| `/customserverhost <IP>` | 指定对外公布的 IP |
| `/serverbandwidthlimitmbps <数值>` | 服务器出站带宽上限（Mbps）。tickrate 提高后若玩家普遍卡顿，可适当放宽 |
| `/tickrate <整数>` | 服务器逻辑/网络更新频率（Hz） |
| `/singleplayer`、`/multiplayer` | 启动模式（服务器包一般不用手动加） |
| `/clientConfigurationCategory`、`/overridenusername`、`/continuegame` | 客户端相关，服务器无意义 |
| `-PlatformInterface`、`-epicuserid`、`-epicusername` | 平台账号相关，服务器无意义 |
| `/dedicatedmatchmakingserver`、`/dedicatedcommunityserver` | 其他服务器形态（非自定义服） |

### 2.2 引擎/启动器层参数

| 参数 | 说明 |
|---|---|
| `/LogOutputPath "<目录>"` | 日志输出目录 |
| `/DisableErrorReporting` | 关闭崩溃收集器弹窗与自动上报（服务器建议加） |
| `_MODULES_*A*B*C*_MODULES_` | 由原生启动器处理，指定要加载的模块列表；加服务端模组时用 |

示例（你当前的实际命令）：

```
DedicatedCustomServer.Starter.exe /dedicatedcustomserverconfigfile "%CONFIG_FILE%" /dedicatedcustomserverauthtoken "%AUTH_TOKEN%" /LogOutputPath "%LOG_DIR%" /tickrate "%TICK_RATE%"
```

## 3. 服务器选项总表（全部 51 项）

范围列来自每个选项上的 `MultiplayerOptionsProperty` 特性（`BoundsMin` / `BoundsMax`）。
**注意：服务器解析配置文件时并不做范围校验**（`DedicatedServerConsoleCommandManager.HandleConsoleCommand` 解析完直接 `SetValue`），越界值不会报错，但属于游戏未定义/不支持的范围。

### 3.1 基础信息

| 选项 | 范围 | 说明 |
|---|---|---|
| `ServerName` | 字符串 | 服务器列表中显示的名字 |
| `WelcomeMessage` | 字符串 | 玩家进入时的欢迎语 |
| `GamePassword` | 字符串 | 加入密码，空 = 无密码 |
| `AdminPassword` | 字符串 | 管理员密码，**务必设置** |
| `StreamerPassword` | 字符串 | 观战/直播密码 |
| `GameDefinitionId` | -2147483648 ~ 2147483647 | 私有游戏定义 ID（一般不用） |

### 3.2 游戏模式与地图

| 选项 | 范围 | 说明 |
|---|---|---|
| `GameType` | 字符串 | 游戏模式：`Skirmish` / `Captain` / `TeamDeathmatch` / `Siege` / `Duel` / `Battle` 等 |
| `PremadeMatchGameMode` / `PremadeGameType` | 字符串 / 0~1 | 预置对局模式 |
| `Map` | 字符串 | 首张地图，如 `mp_sergeant_map_007` |
| `CultureTeam1` / `CultureTeam2` | 字符串 | 两队文化：`empire` `battania` `vlandia` `sturgia` `khuzait` `aserai` |
| `NumOfSlots` | — | 代码中无属性定义（内部使用），不建议手动配置 |

### 3.3 人数与 Bot

| 选项 | 范围 | 说明 |
|---|---|---|
| `MaxNumberOfPlayers` | 1 ~ 1023 | 服务器最大玩家数（实际还受带宽/CPU 限制） |
| `MinNumberOfPlayersForMatchStart` | 0 ~ 20 | 开始第一回合所需最少人数，不够则一直等 |
| `NumberOfBotsTeam1` | **0 ~ 510** | 1 队 bot 数量 |
| `NumberOfBotsTeam2` | **0 ~ 510** | 2 队 bot 数量 |
| `NumberOfBotsPerFormation` | **0 ~ 100** | 每个阵型的 bot 数，仅 `Captain` 模式有效 |
| `AutoTeamBalanceThreshold` | 0 ~ 30 | 两队人数差超过该值自动平衡；0 = 关闭 |
| `MaxStreamerCount` | 0 ~ 100 | 最大观战/直播人数；0 = 禁止 |

### 3.4 回合与计时

| 选项 | 范围 | 说明 |
|---|---|---|
| `WarmupTimeLimitInSeconds` | **60 ~ 3600** | 热身最长时间（秒）。最大 3600 = 60 分钟 |
| `MapTimeLimit` | 1 ~ 60 | 单张地图最长时间（**分钟**） |
| `RoundTimeLimit` | 60 ~ 3600 | 单回合最长时间（**秒**） |
| `RoundPreparationTimeLimit` | 2 ~ 60 | 选兵/选装备时间（秒） |
| `RoundTotal` | 1 ~ 99 | 总回合数 |
| `RespawnPeriodTeam1` / `RespawnPeriodTeam2` | 1 ~ 60 | 死亡后重生等待（秒） |
| `SingleSpawn` | 布尔 | 单次重生模式（死了不再复活） |

### 3.5 经济与计分

| 选项 | 范围 | 说明 |
|---|---|---|
| `UnlimitedGold` | 布尔 | 无限金钱 |
| `GoldGainChangePercentageTeam1/2` | -100 ~ 100 | 金钱获取倍率（百分比增减） |
| `MinScoreToWinMatch` | 0 ~ 1023000 | 获胜所需分数（模式相关） |
| `MinScoreToWinDuel` | 0 ~ 7 | 决斗获胜分数 |
| `PollAcceptThreshold` | 0 ~ 10 | 投票通过所需的赞成/反对差值 |

### 3.6 友伤与战斗

| 选项 | 范围 | 说明 |
|---|---|---|
| `FriendlyFireDamageMeleeSelfPercent` | 0 ~ 2000 | 近战误伤队友时，**反弹给攻击者**的伤害百分比 |
| `FriendlyFireDamageMeleeFriendPercent` | 0 ~ 2000 | 近战误伤队友时，**实际造成**的伤害百分比 |
| `FriendlyFireDamageRangedSelfPercent` | 0 ~ 2000 | 远程误伤反弹百分比 |
| `FriendlyFireDamageRangedFriendPercent` | 0 ~ 2000 | 远程误伤实际百分比 |
| `UseRealisticBlocking` | 布尔 | 真实格挡（受动画进度影响） |
| `AllowIndividualBanners` | 布尔 | 允许玩家自定义旗帜 |

### 3.7 投票与杂项

| 选项 | 范围 | 说明 |
|---|---|---|
| `AllowPollsToKickPlayers` / `AllowPollsToBanPlayers` / `AllowPollsToChangeMaps` | 布尔 | 允许踢人/封人/换图投票 |
| `SpectatorCamera` | 0 ~ 7 | 观战视角模式 |
| `DisableInactivityKick` | 布尔 | 关闭挂机踢人 |
| `EnableMissionRecording` | 布尔 | 录制任务回放 |

### 3.8 阵型标记显示（新增项）

| 选项 | 范围 | 说明 |
|---|---|---|
| `FormationTargetingVisibilityMode` | 0 ~ 2 | 0 关闭；1 按可见兵力百分比；2 按可见兵力绝对值 |
| `FormationTargetingVisibilityThreshold` | 0 ~ 100 | 上一条的阈值 |
| `FormationMarkerFarDistanceCutoff` | -1 ~ 1000 | 超过该距离阵型标记使用 FarAlphaTarget 透明度；-1 = 默认 |
| `FormationMarkerFarAlphaTarget` | -1 ~ 100 | 远距离时标记透明度（百分比）；-1 = 默认 |
| `FormationMarkerAlwaysOnDistance` | -1 ~ 1000 | 该距离内标记始终完全不透明；-1 = 默认 |

## 4. 常用调参场景

### 4.1 缩短热身、尽快开打

```
WarmupTimeLimitInSeconds 60
```

### 4.2 长时间热身等人

```
WarmupTimeLimitInSeconds 3600
```
（上限就是 3600 秒；再大虽然配置文件不会报错，但超出游戏定义范围，不保证生效）

### 4.3 单局更长

```
RoundTotal 9
RoundTimeLimit 900
MapTimeLimit 30
```

### 4.4 加 Bot 打练习局

```
NumberOfBotsTeam1 20
NumberOfBotsTeam2 20
```
- 每队上限 510。
- `Captain` 模式下还要配合 `NumberOfBotsPerFormation`（≤100）。

### 4.5 关闭友伤

```
FriendlyFireDamageMeleeFriendPercent 0
FriendlyFireDamageRangedFriendPercent 0
```

### 4.6 死亡后快速复活

```
RespawnPeriodTeam1 1
RespawnPeriodTeam2 1
```
