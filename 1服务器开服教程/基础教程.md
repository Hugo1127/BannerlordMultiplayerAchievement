# 骑马与砍杀 2：霸主 —— 联机自定义服务器开服教程

> 本文只讲开服流程。参数含义、取值范围、调参场景见 [服务器参数手册.md](./服务器参数手册.md)。

## 1. 环境准备

| 服务器规模 | CPU | 内存 | 硬盘 |
|---|---|---|---|
| 16 人内（决斗、遭遇战） | 2 核，≥ 3.0GHz | 4GB | 10GB，建议 SSD |
| 32 人内（领军、团队死斗） | 4 核，≥ 3.2GHz | 8GB | 15GB，建议 SSD |
| 64 人 + AI（攻城、大规模模组服） | 4 核+，≥ 3.5GHz | 12GB+ | 20GB+，建议 SSD |

- 服务端不需要显卡，瓶颈在 CPU 单核性能；Bot 数量会显著增加 CPU 占用。
- 系统：Windows Server 64 位；Windows 10 / 11 64 位也可，适合先在本机跑通。
- 依赖：只需安装 **Microsoft Visual C++ 2015-2022 Redistributable (x64)** → <https://aka.ms/vc14/vc_redist.x64.exe>
- 服务端自带 .NET 运行时，不需要另装 .NET。
- 部署路径用盘符根目录下的全英文无空格短路径，例如 `C:\DedicatedServer`。
- 可先双击 `bin\Win64_Shipping_Server\DedicatedCustomServer.Starter.exe` 试运行：只能空跑，不会出现在游戏大厅，仅用于初步确认运行环境正常。

## 2. 获取服务端文件

### 2.1 Steam 直接下载（带桌面的服务器）

1. Steam →「库」，左侧分类勾选 **「工具」（Tools）**
2. 搜索 `Mount & Blade II: Dedicated Server`，右键安装

### 2.2 本机装好后上传（纯命令行云服务器）

本机用 Steam 装好后整目录上传：压缩包 + 远程桌面 / 网盘，或 WinSCP、FileZilla 走 SFTP，或用云厂商的文件传输功能。传完校验文件完整性。

### 2.3 目录结构

```
C:\DedicatedServer\
├─ bin\
│  └─ Win64_Shipping_Server\
│     ├─ DedicatedCustomServer.Starter.exe    ← 要启动的就是它
│     ├─ TaleWorlds.Starter.DotNetCore.exe
│     ├─ TaleWorlds.MountAndBlade.dll
│     └─ logs\                                ← 日志目录，start.bat 会自动创建
├─ Modules\
│  ├─ Native\

│  │  ├─ ds_config_sample_*.txt               ← 官方示例配置
```

## 3. 获取服务器授权 Token

没有 Token 只能内网直连，不会出现在公开服务器列表。

1. 启动游戏，进入**多人游戏**并登录联机大厅
2. 按 `ALT` + `` ~ `` 呼出控制台
3. 输入 `customserver.gettoken`
4. 令牌文件位于 `C:\Users\<用户名>\Documents\Mount & Blade II Bannerlord\Tokens\`，有效期 **3 个月**

两种用法：

- **Token 文件**：放在运行服务器的账户的 `Documents\...\Tokens\` 下
- **启动参数**：`/dedicatedcustomserverauthtoken <令牌>`；以计划任务 / SYSTEM 身份运行时必须用这种方式

## 4. 服务器配置

| 层 | 位置 | 作用 |
|---|---|---|
| 启动参数 | `start.bat` | 配置文件路径、Token、tickrate、日志目录、模块列表 |
| 服务器命令 | `Modules\Native\myserver_config.txt` | 服务器启动时逐行执行的控制台命令 |

- 配置文件格式为一行一条 `命令 参数`，不是 `键=值`，改完重启生效。
- 文件**必须放在 `Modules\Native\` 下**。
- 可直接参考官方示例 `Modules\Native\ds_config_sample_*.txt`（共 13 个，覆盖遭遇战、领军、团队死斗、攻城、决斗、自动换图）。
- 全部选项、取值范围与推荐值见 [服务器参数手册.md](./服务器参数手册.md) 第 3、4 章。

最小可用的 `myserver_config.txt` 见同目录 [myserver_config.txt](./myserver_config.txt)；其中的 `CHANGE_ME` 请先替换成你自己的对局密码与管理员密码再开服。

## 5. 启动服务器

### 5.1 推荐：`start.bat`

```bat
@echo off
powershell -NoProfile -ExecutionPolicy Bypass -Command "Set-Location 'C:\DedicatedServer\bin\Win64_Shipping_Server'; New-Item -ItemType Directory -Force 'C:\DedicatedServer\bin\Win64_Shipping_Server\logs' | Out-Null; ./DedicatedCustomServer.Starter.exe /dedicatedcustomserverconfigfile 'C:\DedicatedServer\Modules\Native\myserver_config.txt' /LogOutputPath 'C:\DedicatedServer\bin\Win64_Shipping_Server\logs' /tickrate 60 /DisableErrorReporting _MODULES_*Native*Multiplayer*_MODULES_"
```

需要 Token 参数时，用这一版（在配置路径后面加 `/dedicatedcustomserverauthtoken`）：

```bat
@echo off
powershell -NoProfile -ExecutionPolicy Bypass -Command "Set-Location 'C:\DedicatedServer\bin\Win64_Shipping_Server'; New-Item -ItemType Directory -Force 'C:\DedicatedServer\bin\Win64_Shipping_Server\logs' | Out-Null; ./DedicatedCustomServer.Starter.exe /dedicatedcustomserverconfigfile 'C:\DedicatedServer\Modules\Native\myserver_config.txt' /dedicatedcustomserverauthtoken 'PASTE_YOUR_TOKEN_HERE' /LogOutputPath 'C:\DedicatedServer\bin\Win64_Shipping_Server\logs' /tickrate 60 /DisableErrorReporting _MODULES_*Native*Multiplayer*_MODULES_"
```

要点：

- 整条命令写在一行，不要用 `^` 续行
- cmd 只留一对双引号（`-Command "..."`），内部路径与 Token 一律用单引号
- 所有路径写绝对路径
- Token 明文写在 bat 里，注意保管

同目录 [start.bat](./start.bat) 即上述模板，改路径即可用。

### 5.2 `_MODULES_` 模块列表

格式 `_MODULES_*模块1*模块2*_MODULES_`，模块名 = `Modules\` 下的文件夹名。

- `Native`、`Multiplayer` 为联机必需，放最前
- 自定义模组追加在后面，越靠后优先级越高
- 写了不存在的模块名服务器不会加载

```
_MODULES_*Native*Multiplayer*_MODULES_
_MODULES_*Native*Multiplayer*ChargeTweaks*_MODULES_
```

### 5.3 前台调试

```powershell
cd 'C:\DedicatedServer\bin\Win64_Shipping_Server'
.\DedicatedCustomServer.Starter.exe /dedicatedcustomserverconfigfile 'C:\DedicatedServer\Modules\Native\myserver_config.txt' /LogOutputPath 'C:\DedicatedServer\bin\Win64_Shipping_Server\logs' /tickrate 60 /DisableErrorReporting _MODULES_*Native*Multiplayer*_MODULES_
```

调试时用前台窗口，日志与输出都留在窗口里，随时 `Ctrl+C` 停止。

### 5.4 后台运行 / 开机自启

- 简单方案：`start.bat` 的快捷方式放入 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- 稳定方案：任务计划程序，触发器「计算机启动时」，操作启动 `start.bat`，勾选「不管用户是否登录都要运行」
- 以 SYSTEM 运行时必须使用 `/dedicatedcustomserverauthtoken`，不用 Token 文件

## 6. 网络与防火墙

- 默认端口 **UDP 7210**；同机多开用 `/port` 改成不同端口
- 需要公网 IP（路由器 WAN 口 IP 与 `https://ip.sb` 查到的外网 IP 一致）
- 云服务器：安全组与系统防火墙两道都要放行

Windows 防火墙（管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "Bannerlord DS UDP 7210" -Direction Inbound -Protocol UDP -LocalPort 7210 -Action Allow
```

`netsh` 版本：

```bat
netsh advfirewall firewall add rule name="Bannerlord DS UDP 7210" dir=in action=allow protocol=UDP localport=7210
```

家宽开服：路由器做端口映射 `UDP 7210 → 服务器内网 IP:7210`。

本机检查端口绑定：

```powershell
Get-NetUDPEndpoint -LocalPort 7210 -ErrorAction SilentlyContinue | Format-Table LocalAddress,LocalPort,OwningProcess
```

外网连通性只能靠游戏内直连验证，UDP 发包成功不代表端口已放行。

## 7. 部署服务端 Mod

```
C:\DedicatedServer\Modules\ChargeTweaks\
├─ SubModule.xml
├─ charge_config.xml
└─ bin\
   └─ Win64_Shipping_Server\
      └─ ChargeTweaks.dll
```

DLL 路径必须是 `模块名\bin\Win64_Shipping_Server\xxx.dll`。

| `ModuleCategory` | 加载位置 | 客户端要装吗 |
|---|---|---|
| `Server` | 只在服务端 | 不需要 |
| `Multiplayer` | 服务端 + 客户端 | 必须装 |

启动命令中加入模块名：`_MODULES_*Native*Multiplayer*ChargeTweaks*_MODULES_`。

加载成功后控制台会打印模组自己的初始化日志；没有打印就核对 `_MODULES_` 中的名字、文件夹名大小写、`SubModule.xml` 的 `DllName` / `SubModuleClassType`。

上面这个 `ChargeTweaks` 就是本仓库自带的示例模组，完整的安装、配置、验证与回滚步骤见[子栏目 2](../2马匹冲撞伤害放大mod开发/部署与使用指南.md)。

## 8. 注意事项

- 参数名写错不会报错，只会被静默忽略；改了没反应先核对拼写与大小写。版本更新后参数可能变化，以 [服务器参数手册.md](./服务器参数手册.md) 为准。
- 地图与 `GameType` 必须匹配，官方图也只能用于对应模式：

  | 地图前缀 | `GameType` |
  |---|---|
  | `mp_skirmish_map_*` | `Skirmish` |
  | `mp_sergeant_map_*` | `Captain` |
  | `mp_tdm_map_*` | `TeamDeathmatch` |
  | `mp_siege_map_*` | `Siege` |
  | `mp_duel_*` / `mp_duel_mode_map_*` | `Duel` |
  | `mp_battle_map_*` | `Battle` |

- `tickrate` 默认 60；120 更流畅但 CPU 与带宽约翻倍，Bot 多时保持 60。
- 不要修改 `Modules\Native\ModuleData\` 下的官方数据，Steam 更新会覆盖；正式服请用独立模块实现。
- 同一账号可同时运行的自定义服务器数量有限，以账号实际为准。
